# CampusX

## What is CampusX?
CampusX is a modern, full-stack social networking and utility application tailored for college and university campuses. It features social feeds, instant messaging, event discovery, an internal marketplace, group tools, and campus location tracking.

## Repository Structure
- **Mobile App**: `apps/mobile/` (Expo / React Native)
- **Backend API**: `apps/backend/` (Node.js / Express / Socket.io)
- **Scripts**: `scripts/`
- **Documentation**: `docs/`
